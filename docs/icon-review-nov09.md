# Icon revisions following November 9 review

Eleven rejected icons are revised individually. Approved icons and entity
geometry remain unchanged; source dependencies are limited to the changed icons.

- DDR–DDR5: tilted DIMMs with physical connector key notches, side retention
  cutouts, visible contacts, packages and generation-specific spreaders.
- Transistor: the Aseprite export is the visual reference. A projecting copper
  radiator tab has a real through-hole, with black encapsulation and three leads.
- Control Board: green laminate with recognizable logic packages, component pins,
  copper routing and capacitors instead of an almost empty socket board.
- GPU: a recognizable dual-fan expansion card, PCIe contacts and output bracket.
  This replaces the rejected bare package silhouette only for this icon.
- Computer Assembler, Crystal Puller and Cooling Tower: icon-only source adapters
  remove the empty foundation and peripheral equipment. Compact icon supports
  frame the assembler's insertion pose and the puller's grown boule. The cooling
  icon uses a three-quarter composition of both radiator/fan cells. Entity sources
  and animations are intact.

Revisions go through the shared GPU render and exact 64px PNG review. They do
not inherit decisions from previous candidates. Approval/publication stay separate.
