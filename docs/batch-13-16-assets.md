# Batches 13–16 — memory, semiconductor materials and model cartridges

Candidate authoring, 2026-11-09. Twenty independent 64×64 RGBA icons use
64-sample HIP GPU Cycles through Asset Studio.

| Batch | Icons |
|---|---|
| 13 | Datacenter, DDR, DDR2, DDR3, DDR4 |
| 14 | DDR5, Discrete Transistor, Disk Pack, DRAM, Control Board |
| 15 | Error-Corrected Qubit, Etchant, Etched Wafer, Exposed Wafer, FOUP Dock |
| 16 | FOUP, Frontier Model, General Model, Glass, GPU |

Datacenter and FOUP Dock reuse their entity sources without editing existing
geometry. Memory modules share gold edge contacts and a coherent visual family:
generations differ in board colour, component layout, marker strips and heat
spreaders. DDR5 has a central power package; DRAM has older discrete leads.
These features distinguish icons, not actual in-game component counts or capacity.

The transistor has three leads and a metal mounting tab. Disk Pack exposes
stacked platters and a lifting handle. The early Control Board uses valve sockets,
consistent with its role before modern integrated controllers. Corrected Qubit
is a shielded array of superconducting loops. Etchant uses an amber hazard-labelled
bottle. Exposed Wafer has a violet resist pattern; Etched Wafer has blue silicon
and raised die islands. FOUP is an amber front-opening carrier. General and
Frontier Model cartridges differ in green/purple graph topology and reinforcement.
Glass is a stack of three edged transparent panes; GPU is a die and adjacent HBM
on an interposer rather than the separately rendered Accelerator Board.

Inspect exact output at 64px, 32px and enlarged sizes. Each icon is reviewed
separately in the finished-art queue, with its Blender file retained. No prototype,
recipe, capacity, installed graphic, or previous model approval is changed by
staging. Publication still requires exact-art approval and isolated validation.
