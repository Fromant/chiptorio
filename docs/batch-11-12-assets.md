# Batches 11 and 12 — machine and process icons

Candidate authoring, 2026-11-09. Ten individual 64×64 RGBA icons use the shared
Asset Studio pipeline and 64-sample GPU Cycles rendering.

Batch 11: CMP Slurry, Computer Assembler, Construction Core, Coolant and
Cooling Tower. Batch 12: Cooling Unit, Cryogen, Cryostat, Crystal Puller and
Datacenter Lab.

The six machine icons reuse their existing entity sources without altering
geometry or model approvals. Slurry is a cream polishing-reagent bottle with
an ochre safety cap. Coolant is a blue handled canister. Cryogen is an insulated
metal Dewar with a frost-coloured snowflake plaque. Cooling Unit is a compact
finned heat exchanger with a fan, grille, copper tubes and hose couplings.

Inspect exact icon PNGs at native 64px, reduced 32px and enlarged sizes. Each
is an independent finished-art candidate with its own Blender download. Batch
bundles remain in production history. Installed icons and game behavior are
unchanged until exact-art approval, isolated validation and explicit publication.
