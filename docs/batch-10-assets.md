# Batch 10 — machine miniatures, die and chiplet

Candidate authoring, 2026-11-09. Five separate 64×64 RGBA icon candidates use
the shared Asset Studio pipeline, GPU Cycles and 64 samples.

Answer Engine, Assembly Fab and Circuit Assembler reuse their entity authoring
sources as miniature silhouettes. The source geometry is not edited or unlocked;
the icon uses a separate output target, still frame and image packing stage.
Bare Die is an exposed polished silicon square with functional blocks and gold
bond pads. Chiplet is a smaller known-good die on a visibly larger ceramic
interposer, with fanout conductors, contacts and decoupling components.

CPU model preparation may proceed while a previously requested animation runs.
GPU icon renders wait for the active web-app job to finish. Exact 64px outputs
are inspected at native size, at 32px and enlarged before handoff. Each candidate
appears separately in the finished-art review queue. Production icons remain
unchanged until explicit approval, isolated validation and publication.
