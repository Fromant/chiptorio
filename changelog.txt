Version: 0.9.0
Date: 2026-10-27
  Features:
    - Added half-node process qualification. The ten refinements from 6 µm to 2 nm are now real two-stage upgrades: the technology unlocks a pilot line and a Metrology Lab, and the yield, compute and power bonus only activates once the lab has analysed a batch of Process Qualification Wafers.
    - Added the Metrology Lab, a lab clone whose inputs are the ten qualification wafers. It cannot research and has no module slots; it only analyses pilot batches.
    - Added the Metrology Test Structure and one pilot recipe per half-node. The recipe runs in the fab of the node it refines and consumes that node's wafers, its base mask, photoresist and a test structure per wafer.
    - Added ten refine technologies. Each costs half of the node it refines, sits directly behind it, and unlocks the Metrology Lab, the test structure and its own pilot recipe. The Question now requires every refinement.
    - Added a qualification section to the network monitor: wafers analysed, batch size, and the exact reason the bar is stopped.
    - Added a debug interface: /c remote.call("chiptorio-qualification", "status"), "evaluate", "state" and "step".
    - Added a pure qualification allocator with unit tests, data-contract checks for the lab, wafers, pilot recipes and refine technologies, and a runtime probe that qualifies 6 µm offline and 800 nm through a network gate.
  Balance:
    - 6 µm and 1.5 µm work without the internet so the early ladder cannot deadlock. From 800 nm the Metrology Lab needs a network that meets a compute floor, a memory dataset and a bandwidth gate.
    - Qualification gates stay scalar-only up to 130 nm; 65 nm and later ask for a scalar/vector split. A vector requirement before the GPU exists would deadlock the ladder.
    - Yield improves the refined node's wafer and die output by 10–25%. Compute improves every chip by 5–20%. Provider power and heat fall by 5–20%. Memory capacity and backplane bandwidth are never scaled.
    - Batches run from 50 to 150 wafers at 1.5–3 seconds each. Extra labs on the same network speed the batch up, but are not required.
    - A qualified upgrade is global and permanent for that force, and persists across save/load. There are no random failures.
  Bugfixes:
    - Node wafer and die recipes now allow productivity, which the qualification yield bonus needs; before this they silently ignored it.
    - The 1.4 nm process technology pointed at a mistyped icon path, so its icon was missing. The generator now writes process-1-4nm.png and the stale dotted file is gone.

Version: 0.8.0
Date: 2026-10-27
  Features:
    - Added the twelve-node process ladder from 10 µm to 1.4 nm. Each node is a manufacturing family: a lithography mask set, exposed wafers, diced dies, a technology and a set of packaging recipes for the architecture chips that node supports.
    - Nodes feed the existing six architecture modules instead of inventing new chip names. A node makes the integrated circuit, microprocessor, system on a chip, GPU, multi-core CPU and quantum processor available at that node's die cost; the compute profiles never change.
    - Die yield rises from 40 to 400 per ten wafers across the ladder, and each node unlocks the packaging recipes for its chip family, from wire-bond ICs at 10 µm to hybrid-bonded quantum processors at 1.4 nm.
    - Added ten half-node refinements (6 µm to 2 nm) to the pure node table ahead of the Metrology Lab. Half-node bonuses accumulate over every completed refinement up to the queried node.
    - Added two science packs: optical discs and HBM stacks. Nine workloads are now required: punched cards, punched tape, magnetic tape, disk packs, solid-state drives, mainframe modules, optical discs, HBM stacks and qubit arrays.
    - Every research computer now accepts all nine packs plus microprocessors, and the Answer Engine requires all nine workloads.
    - Added node technology icons and generated icons for optical discs, HBM stacks and every process node.
    - Documented the node model, the nine-pack mapping and the new 2.1 prototype-name and science-pack traps in DESIGN.md.
    - Added a unit spec for the node table and data-contract checks for every node's items, recipes, technology and packaging effects, the nine-pack lab inputs, and the quantum pack rename.
  Balance:
    - Nodes 10 µm, 3 µm and 1 µm run in the Wafer Fab. From 350 nm the wafer and die recipes move to the VLSI Fab and consume coolant.
    - Nodes from 350 nm to 1.4 nm are compute-gated, rising from 8 compute, 16 memory and 8 bandwidth to 192 compute, 384 memory and 192 bandwidth. The first three nodes stay offline so they can be researched without a network.
    - The last node is listed internally as process-1-4nm because prototype names cannot contain dots; its display label remains 1.4 nm.
    - VLSI Process keeps its machines and chemistry but no longer unlocks wafers, dies or the system on a chip; those are node content now.
    - Planar Process no longer unlocks integrated circuits; Microarchitecture now requires the 3 µm node and has no effects of its own.
    - Advanced Packaging unlocks only the chiplet and HBM stack; Heterogeneous Compute and Quantum Advantage are pure gates.
    - The Datacenter technology now also requires the 350 nm node.
    - The Question requires the 1.4 nm node, all nine science packs and microprocessors.
    - The quantum science pack is renamed to chiptorio-quantum-science-pack throughout labs, technologies and the Answer Engine.
  Bugfixes:
    - The unit suite no longer stops after the graph spec, so research spec failures are reported again. The greedy lab test now expects four active labs from eight compute at two per lab.

Version: 0.7.0
Date: 2026-10-27
  Features:
    - Research now runs on network compute, memory and bandwidth. Every lab is a network client: it pauses when the network cannot feed it, and the research bar decays while it is starved.
    - Added the Server Rack and Datacenter compute providers, and the Memory Bank storage provider. Each holds chips or memory modules in its module slots; installed modules are summed into the network's compute, memory and bandwidth.
    - Added six compute modules: integrated circuit, microprocessor, system on a chip, multi-core CPU, GPU and quantum processor. They are module prototypes with an empty vanilla effect, so the script owns their value.
    - Added SRAM and DRAM memory modules. SRAM is cheap and small; DRAM is the datacenter-scale generation.
    - Added per-technology compute gates: VLSI Process, Datacenter, Advanced Packaging, Heterogeneous Compute, Quantum Computing, Quantum Error Correction, Quantum Advantage and The Question each require a compute floor, a memory dataset and bus bandwidth. Mixed scalar/vector/quantum profiles cannot be covered by surplus of one kind.
    - Added a pure allocation and decay module with unit tests, and a research runtime that pauses labs, applies decay and exposes a debug remote interface.
    - The Assembly Fab (formerly the Server Rack crafting machine) packages chips, systems, GPUs and multi-core CPUs, so the Server Rack can be a compute provider instead of a crafting machine.
  Balance:
    - The Internet technology now also unlocks the Assembly Fab, the Server Rack, the Memory Bank, SRAM and the wiring. It remains free of compute.
    - VLSI Process is the first compute-gated technology and requires the Internet.
    - The Datacenter technology unlocks the Datacenter provider, the Datacenter Lab and DRAM.
    - Decay is capped at 2% of the research bar per minute. A pure compute shortfall decays in proportion to the gap; memory and bandwidth shortfalls are hard stops.
  Bugfixes:
    - A lab that fails the network gate no longer keeps consuming science packs.
    - Module inventories are polled once per second, so inserting a chip takes effect without a rebuild event.

    - Removed microprocessor and system-on-chip costs from roboports and GPU and quantum-processor costs from the spidertron; those prototypes are no longer buildable.
  Bugfixes:
    - The data stage no longer requires the deleted technology-gate metadata module.
